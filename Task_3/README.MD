# 📊 E-Commerce Sales Data Analysis

## 📌 Project Overview

This project is based on **E-commerce Sales Data Analysis**.
The main goal is to understand business performance, customer behavior, and sales trends using data.

---

## 📂 Project Files

* `clean_data.csv` → Final cleaned dataset
* `ecommerce_sales_data.sql` → SQL queries for data cleaning and analysis
* `EDA_REPORT_TASK_3.docx` → Detailed analysis report
* `TASK_3_DASHBOARD_NEW.pbix` → Power BI dashboard

---

## 🧹 Data Cleaning Steps

We performed the following steps to clean the data:

* Converted data types (date, numbers)
* Checked missing values (No null values found ✅)
* Removed duplicate records
* Checked incorrect/future dates
* Checked negative values
* Cleaned text (fixed spaces & capitalization)

---

## 📊 Key Insights

### 💰 Business Performance

* Total Sales: **10,628,823**
* Total Profit: **1,835,918**
* Total Orders: **3492**
* Profit Margin: **17.28%**

---

### 👥 Customer Analysis

* High Spenders: **14%**
* Medium Spenders: **30%**
* Low Spenders: **56%**
* Repeat Customers: **189**

---

### 🌍 Regional Analysis

* Highest Sales Region: **West**
* Other regions: East, South, North

---

### 📦 Product Analysis

* Top Category: **Electronics**
* Other Categories: Accessories, Office Supplies
* Top Products:

  * Laptop (Highest Revenue)
  * Smartphone (Most Sold)
  * Tablet (Good Profit)

---

## 🧠 SQL Analysis

Some important business questions solved:

* Total sales and profit calculation
* Profit margin
* Customer segmentation
* Repeat customers
* Regional performance
* Top categories and products

---

## 📈 Dashboard

Power BI dashboard is created to visualize:

* Sales trends
* Customer behavior
* Regional performance
* Product performance

---

## 🎯 Conclusion

This project helps in:

* Understanding customer behavior
* Identifying top-performing regions & products
* Improving business decisions using data

---

## 🚀 Tools Used

* SQL (PostgreSQL)
* Excel / CSV
* Power BI
* MS Word
